*How do I use this whimsical port scanner?*:

1)install Python 3.13.5 at https://www.python.org/downloads/release/python-3135/ 

2)install the PILLOW module!:

-Windows: 

pip install Pillow

-Linux: run:

python3 -m venv my-env
source my-env/bin/activate
pip install pillow

-MacOS:

pip install pillow

3) RUN MY SCANNER!:

run: 

python StarryScannerApp.py (FOR GUI USERS)

python StarryScannerCLI.py (FOR CLI USERS)
